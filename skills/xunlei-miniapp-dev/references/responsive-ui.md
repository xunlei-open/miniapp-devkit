# 响应式布局

## 默认布局

- 新应用默认使用 `manifest.window: { width: 900, height: 600 }`，优先让 UI 适配窗口；业务确有需要时可调整，用户指定或已有工程的尺寸优先。Electron 的 width / height 表示内容可视区，不含标题栏与边框；省略时默认 900 × 600。创建时宽高分别至少为 480 / 320，拖动缩放的最小外框为 480 × 320，不锁定比例；布局仍以实际视口为准。
- 默认不设置应用级 Header（独立的品牌、Logo 或标题栏），页面直接进入核心功能区；用户明确要求时可添加。返回、搜索、筛选等功能控件和区域标题按需保留。
- 桌面默认状态的主要内容与操作尽量一屏可见。长列表或展开内容可在局部滚动；窄屏、文字放大时允许必要的纵向滚动。不要通过裁切、缩小文字或整页缩放实现一屏布局。
- 采用移动端优先的响应式布局，同一套页面适配窄窗口到桌面宽屏。这里约定的是布局方式，宿主 API 的平台支持仍以目标客户端为准。

## 实现要点

保留视口声明并允许用户缩放：

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

布局方式按内容选择；Flex / Grid 的可收缩区域可用 `min-width: 0`、`min-height: 0` 或 `minmax(0, 1fr)`。长文件名、弹窗和宽表格应有可达的换行或滚动方式，固定操作栏不遮挡正文。核心操作兼顾触控与键盘。

## 主题适配

使用 `prefers-color-scheme` 媒体查询适配深浅主题。迅雷宿主切换主题时会自动同步到微应用的媒体查询结果，无需调用宿主 API 或刷新页面。

## 验证

UI 改动先按最终窗口尺寸检查，再按内容选择代表性的窄屏和宽屏，查看长内容、空状态、错误状态及文字放大后的表现。确认无非预期溢出、遮挡或不可达操作，无需为小改动固定跑一整套尺寸。

浏览器用于验证布局，平台调用在目标迅雷客户端验证；无法预览时说明尚未验证的部分。
